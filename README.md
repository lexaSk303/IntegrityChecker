# Вариант 06. Анализатор целостности файлов

**СТАРТОВЫЙ ПРОЕКТ ДЛЯ СТУДЕНТА**

**Покрываемые темы:** SHA256, LINQ, PLINQ, Parallel, JSON, реестр

## Условия зачёта

Выполнить 7 обязательных заданий. Дополнительные задания повышают оценку. Код должен собираться на .NET 9.
Не допускаются пустые `catch`, блокирующие ожидания в UI-потоке и небезопасное совместное изменение состояния.

## Обязательные задания
1. Получить список файлов в каталоге.
2. Вычислить SHA256 каждого файла.
3. Сохранить контрольные суммы в JSON.
4. Сравнить текущие хеши с предыдущим снимком.
5. Реализовать параллельное вычисление хешей.
6. Сравнить LINQ и PLINQ по времени и корректности.
7. Корректно закрывать файловые потоки.

## Дополнительные задания
8. Добавить Channel и ограниченное число worker-ов.
9. Вывести новые, изменённые и удалённые файлы.
10. Сохранять путь последнего снимка в HKCU.

## Требования к сдаче

- Сохранить комментарии `TODO` и заменить их реализацией.
- Добавить отдельные классы для моделей и сервисов.
- Приложить 3–5 тестовых сценариев или пошаговую инструкцию проверки.
- Подготовить устное объяснение архитектуры и одного исправленного дефекта.
